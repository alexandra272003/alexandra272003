<br/>

Ensures DataFrames are always clean before they reach your function — automatically and consistently. Built to eliminate the repetitive, easy-to-forget manual cleaning that breaks real-world pipelines.

```python
from cleanframe import cleanframe

@cleanframe(drop_nulls=True, normalize=["age", "salary"])
def process_employees(df: pd.DataFrame) -> pd.DataFrame:
    return df.groupby("department").mean()
```

`Python` · `Pandas` · `Decorators` · `PyPI` · `MIT`
